# Research

Rules for researching FoundryVTT and related library behavior.

## Pattern/Rule

- Use Context7 to look up FoundryVTT v14 APIs and related libraries.
- Alternatively use the official FoundryVTT API documentation at `https://foundryvtt.com/api/`.
- Prefer official FoundryVTT API documentation for API behavior.
- If documentation is ambiguous, record the assumption in code comments or implementation notes.

## Rationale

FoundryVTT APIs and related libraries can change. Implementation decisions should be based on current official documentation whenever behavior matters.
