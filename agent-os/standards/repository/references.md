# References

Rules for the read-only `references/` directory.

## Pattern/Rule

- Never add, update, or delete files within `references/` or any subdirectory.
- Use files in `references/` only as local read-only research material.

## Rationale

The references tree contains external or copied reference material. Keeping it read-only prevents accidental vendor or documentation drift.
