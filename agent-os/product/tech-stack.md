# Tech Stack

Pocket Foundry is a TypeScript FoundryVTT module.

## Runtime

- FoundryVTT v14+
- Module source root: `src/`
- Built module output: `dist/pocket-foundry/`

## Languages And Templates

- TypeScript for source and scripts
- Handlebars templates
- Tailwind CSS for module styles

## Tooling

- npm
- TypeScript
- Vitest
- esbuild
- Tailwind CSS CLI

## Commands

```bash
npm install
npm test
npm run build
```
