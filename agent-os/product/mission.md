# Mission

Pocket Foundry provides a mobile-optimized player experience for FoundryVTT v14+, including character-sheet workflows and compact content browsing.

## Goals

- Make common player workflows comfortable on mobile screens.
- Keep the addon core system-agnostic.
- Support concrete game systems through isolated adapters.
- Preserve Foundry permission, visibility, and document behavior.

## Current Scope

- Module ID: `pocket-foundry`
- Foundry compatibility: v14
- Current built-in system adapter: `dnd5e`
